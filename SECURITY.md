# Security Policy

## 🔒 Supported Versions

We actively release security and data privacy patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## 🛡️ Reporting a Vulnerability

The security of candidate personally identifiable information (PII) and recruitment data processing is our top priority.

If you discover a security vulnerability, data leakage issue, or potential bypass of privacy safeguards in **Ziara TalentX**, please follow these responsible disclosure steps:

1. **Do NOT open a public GitHub issue.** Public issues expose sensitive vulnerabilities before a fix is available.
2. **Email the maintainers directly:** Send an encrypted or confidential email to **[ziaratechqlabs@gmail.com](mailto:ziaratechqlabs@gmail.com)** with the subject line:  
   `[SECURITY] Vulnerability Report - Ziara TalentX`.
3. **Include Detailed Information:**
   - Detailed description of the vulnerability.
   - Steps to reproduce or proof-of-concept (PoC) code/files.
   - Potential impact on candidate data or host machines.
   - Your name or GitHub handle for attribution (if desired).

### Our Commitment:
* **Response Time:** We will acknowledge receipt within **48 hours**.
* **Remediation:** We will assess and prepare a patch within **7 business days**.
* **Attribution:** Once patched and published in a security advisory, we will publicly acknowledge your contribution (unless you prefer anonymity).

---

## 📜 Ethical Data Guidelines
This project strictly prohibits storing, committing, or scraping real candidate PII without legal consent. Review [LEGAL.md](LEGAL.md) for data compliance requirements (DPDP Act 2023, GDPR, CCPA).
